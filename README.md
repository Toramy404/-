# 渡夜手册

《艾尔登法环：黑夜君临》的非官方离线资料工具。黑环攻略的本地集成，AI 辅助整理与开发；资料来自社区，核验范围和未决差异随数据保留。

**当前应用版本：v0.4.1（手机试用版） · 数据快照：2026.10.14-r2 · Android 8.0 及以上。**

支持词条分组与档位比较、局内/局外分类、夜王属性、两夜 Boss 反查、大空洞水晶点位、角色和技能、事件、收藏、历史记录及显示设置。全部查询资料随本地网页或 APK 携带，应用不申请网络与存储权限。

## 直接看效果

电脑安装 Node.js 22 或以上后，在此目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:4317/>。不需要 `npm install`，没有运行时 npm 依赖。Windows 也可双击 `打开渡夜手册.cmd`。右上角“手机预览”可以切换窄屏布局，改完刷新即可；不需要每次安装 APK。无 Node 时，可直接打开 `dist/index.html`。

这是本机预览地址。手机安装包和覆盖升级说明见 [安卓说明](android/README.md)；公开下载以 [Releases](https://github.com/Toramy404/-/releases) 实际附件为准。APK 二进制不写入 Git；v0.4.1 本机安装包为 `release/渡夜手册-v0.4.1.apk`，历史安装包保留。

## 开发入口

- [开发、验收与发版流程](docs/DEVELOPMENT.md)：从一个需求到一个可回退版本。
- [数据维护规则](docs/DATA.md)：来源、数值纠错、分组与再生成。
- [更新记录](CHANGELOG.md)：已交付版本与尚未发版的修改。
- [第三方来源与许可](THIRD_PARTY_NOTICES.md)：程序代码与游戏素材的授权边界。

```sh
npm run check
npm test
python scripts/build_data.py --check
```

Python 需 3.10 或以上。CI 会运行相同检查，并编译不含发布签名的 Android 包。它不代替手机安装、覆盖升级、断网、返回退出和导出测试。

## 目录

| 目录 | 用途 |
| --- | --- |
| `dist/` | 直接运行的网页源码、生成的数据包与离线图片；本项目没有前端编译框架 |
| `data/` | 可维护的 JSON 数据源、来源、纠错和疑问记录 |
| `android/` | Android WebView 宿主、资源和版本号 |
| `scripts/`、`tests/` | 数据生成、构建与回归检查 |
| `.github/` | 自动检查、问题表单和合并说明模板 |
| `docs/` | 维护办法 |
| `release/` | 本机安装包，Git 只收录说明；公开安装包应放 Releases |

## 已验证和待确认

873 条效果原记录按场景形成 722 个入口，保持原有 617 个同名组的对应关系。分组只组织显示，不重算数值，不为无编号记录猜测档位。

520 种地图配置的两夜主要 Boss 已跨表核对；词条仍有 294 条未完成第二来源逐项语义验证，部分角色属性来源仍有差异。详情保留条件、来源与待核验说明。资料快照日期不是游戏版本，普通/深夜/永夜数据不能互换。

v0.4.1 沿用既有包名与签名，以 v0.4.0 为覆盖升级基线。构建时检查签名、版本递增与资源一致性；手机试用验收待补。浏览器预览通过不等于手机全部行为通过。
